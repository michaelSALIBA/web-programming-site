1989: Proposal for the World Wide Web

Tim Berners-Lee submitted a proposal at CERN titled "Information Management: A Proposal". This event laid out the conceptual blueprint for a global, linked database using hypertext, solving the issue of lost or isolated information across different systems.

1990: First Website, Server, and Web Technologies Launched

Berners-Lee specified the three foundational technologies of the Web—HTML (language), HTTP (protocol), and URL (addressing system)—and launched the first web server (info.cern.ch) and browser on a NeXT computer. The core protocols that define how documents are written, located, and transferred across the network were formally operationalized.

1993: CERN Releases Web Software to the Public Domain

On April 30, 1993, CERN made the World Wide Web underlying source code available on a royalty-free, public domain basis. By making the core technology open and free rather than proprietary, CERN allowed developers worldwide to build software and web servers without licensing barriers, spurring exponential internet adoption.

1994: Founding of the W3C & Launch of Commercial Browsers

Tim Berners-Lee established the World Wide Web Consortium (W3C) to define open standards. Simultaneously, Netscape Communications released Netscape Navigator. Standardized web technologies prevented the Web from fragmenting into incompatible proprietary networks, while commercial browsers sparked the initial e-commerce boom.

1995: Rise of Dynamic Web Pages & Client-Side Scripting

Brendan Eich developed JavaScript (initially LiveScript) for Netscape Navigator, and Sun Microsystems released Java. Web pages transitioned from static text documents to interactive applications capable of running client-side code dynamically in real time.

1996: CSS Introduced for Visual Standardisation

The W3C published the first official specification for Cascading Style Sheets (CSS1). It separated document structure (HTML) from visual presentation (style), drastically simplifying web maintenance and enabling complex layout design.

2004: Web 2.0 and the Interactive Web Era

Platforms like Ajax-driven web applications (e.g., Gmail) and user-generated content networks (e.g., Flickr, Facebook) transformed how users interacted online. The Web shifted from a read-only platform to a read-write ecosystem driven by user-generated content, rich internet applications, and social connections.

2007–2008: The Mobile Web & HTML5 Shift

The release of smartphones with full mobile browsers (2007) and the introduction of the HTML5 draft standard (2008) changed media consumption. HTML5 eliminated reliance on third-party plugins (like Adobe Flash) for video and audio, standardizing cross-platform web capabilities across desktop and mobile devices.

2014–2018: Ubiquitous Web Encryption (HTTPS Priority)

Major browser vendors and initiative initiatives like Let's Encrypt pushed for universal transport security, prioritizing HTTPS over unencrypted HTTP. End-to-end encryption became standard across the web, protecting user privacy, securing web transactions, and preventing data tampering at scale.
